# PROGRAM

**Speaking:** Gregg, Judd (G000445) [R-NH]

```
                                PROGRAM

  Mr. GREGG. Tomorrow, the Senate will continue its work on the deficit 
reduction bill, and under the time agreement, all time will expire at 6 
p.m. tomorrow evening. I remind my colleagues to work with the bill 
managers if they plan to offer amendments. We will complete this bill 
this week. We will work through Thursday and Friday, if necessary, to 
finish this important measure. I encourage Senators to be judicious in 
offering amendments so that we can avoid a multiday vote-arama that 
will spill into Friday's session.
  I remind Senators that we will need to dispose of the Agriculture 
appropriations conference report this week as well, and we will be 
slotting in debate time for that probably tomorrow evening.

                          ____________________
```
