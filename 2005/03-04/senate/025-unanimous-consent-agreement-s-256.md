# UNANIMOUS CONSENT AGREEMENT--S. 256

```
                  UNANIMOUS CONSENT AGREEMENT--S. 256

  Mr. ISAKSON. Mr. President, I ask unanimous consent that 
notwithstanding rule XXII, Senators have until 2:30 p.m. on Monday, 
March 7 to file first-degree amendments to S. 256, the bankruptcy bill, 
and until 12 noon on Tuesday, March 8, to file second-degree 
amendments.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
