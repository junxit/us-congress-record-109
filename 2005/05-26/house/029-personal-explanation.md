# PERSONAL EXPLANATION

**Speaking:** Fattah, Chaka (F000043) [D-PA]

**Measures:** H.R. 3

```
                          PERSONAL EXPLANATION

  Mr. FATTAH. Mr. Speaker, I inadvertently voted against the Motion to 
Instruct Conferees on H.R. 3, which instructs conferees to increase 
funding for the Transportation/Highway bill. The motion would increase 
the minimum guaranteed rate of return to 92 percent, while ensuring 
that each state receives no less than what is provided under the bill.
  I request that the record reflect that I support the motion and I 
intended to vote for it.
```
