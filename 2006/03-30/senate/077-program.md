# PROGRAM

**Speaking:** Frist, William H. (F000439) [R-TN]

```
                                PROGRAM

  Mr. FRIST. Mr. President, today we had some good debate, made good 
progress, had good discussion on this border security bill. We had 
hoped to have more votes on amendments to this bill this evening. We 
were unable to make that progress. But we will return tomorrow and try 
to set up votes on the three pending amendments.
  Again, I am disappointed we could not schedule more action on this 
bill this week in terms of votes. We have Senators who are waiting to 
offer amendments, so I hope tomorrow we can reach agreement for a time-
certain for the next votes. It is clear to me at this point that we 
will not be able to set any votes for tomorrow, and therefore I 
announce now that there will be no votes tomorrow. We will have 
multiple votes on Monday, and we will announce that schedule on Friday.

                          ____________________
```
