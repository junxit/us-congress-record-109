# PROGRAM

```
                                PROGRAM

  Mr. STEVENS. Mr. President, tomorrow the Senate will finish 
consideration of the port security bill. The cloture vote will occur at 
approximately 11 a.m. The leader urges our colleagues on both sides of 
the aisle to vote for cloture so that we can expedite passage of this 
important bill. Following the cloture vote, the bill's manager will 
work through the remaining amendments. Senators should expect votes 
throughout the day.
  I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The legislative clerk proceeded to call the roll.
  Mr. STEVENS. Mr. President, I ask unanimous consent that the order 
for the quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
